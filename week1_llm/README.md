# Week 1 — LLM 다루기

이번 주는 **LLM 을 코드로 부르는 가장 작은 단위** 를 익힙니다.
다음 주(에이전트) 부터 모든 코드가 이 위에 쌓입니다.

## 학습 목표

- `genai.Client` 로 Gemini 에 연결한다
- `client.models.generate_content()` 한 번 호출해서 응답을 받는다
- 단발성 호출과 멀티턴(history 누적) 의 차이를 안다

## 파일과 실행 순서

| # | 파일 | 무엇을 배우나 |
|---|---|---|
| 1 | `hello.py` | 가장 단순한 LLM 호출 한 번 |
| 2 | `chat.py` | history 누적으로 멀티턴 대화 |

```bash
# 가상환경 활성화 후
python hello.py
python chat.py
```
