# Week 2 — 에이전트의 정체

이번 주가 **강의 전체에서 가장 중요한 회차** 입니다.
"에이전트" 가 무엇인지, 마법 같은 단어를 코드로 분해해서 정체를 봅니다.

## 핵심 메시지

> **에이전트 = LLM + 도구 + 반복 루프**
>
> 그게 전부. LangChain · CrewAI 같은 프레임워크는 이 위에 편의 기능을 얹은 것일 뿐.

## 학습 목표

- `function_declarations` 로 LLM 에게 "쓸 수 있는 도구" 를 알려준다
- LLM 응답이 텍스트 대신 `function_call` 일 수 있다는 것을 직접 본다
- 도구 결과를 다시 LLM 에게 돌려주는 흐름 (콜센터 비유)
- 그 흐름을 `while` 로 감싸면 → 에이전트

## 파일과 실행 순서

| # | 파일 | 무엇을 배우나 |
|---|---|---|
| 1 | `tool_use.py` | Tool Use 한 턴만 수동으로 — 4 단계 흐름을 손으로 따라간다 |
| 2 | `agent_loop.py` | 그 흐름을 루프로 감싸고 도구 2개로 확장 — **이것이 에이전트** |

```bash
python tool_use.py
python agent_loop.py
```

## 비유: 콜센터

- **LLM** = 상담원 — 말을 잘 하지만 시스템 직접 못 만짐
- **Python 코드 (우리)** = 시스템 — 계좌 조회, 잔액 확인 등 실제 작업
- 상담원이 "시스템에 조회 요청" 하면 우리가 결과를 돌려주고, 상담원이 그걸 보고 고객(=사용자) 에게 자연어로 답함
- → 이게 곧 tool use 의 본질
