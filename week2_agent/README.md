# Week 2 — 에이전트의 정체

이번 주가 **강의 전체에서 가장 중요한 회차** 예요.
"에이전트" 라는 단어를 코드로 분해해서 정체를 드러내는 시간.

## 이번 주에 배우는 것

- LLM 이 **텍스트 대신 함수 호출 요청** 을 돌려줄 수 있다는 것
- 그 요청을 받아서 **우리 코드가 함수를 실행하고 결과를 돌려주는** 패턴
- 이걸 `while` 로 감싸면 = **에이전트**

## 회차 끝나면 답할 수 있어야 하는 질문

1. LLM 이 "함수를 호출했다" 는 게 무슨 뜻인가? (= `function_call` 의 정체)
2. 도구가 없으면 LLM 이 못 하는 일은 무엇인가?
3. `while` 루프가 왜 필요한가? 한 번에 끝나면 안 되나?
4. **Copilot 이 짜준 agent loop 코드를 보고 옳은지 평가할 수 있는가?**

→ 이 네 가지가 본인 입에서 자연스럽게 나오면 회차 성공.

---

## 무엇을 만들 건가

**날씨를 묻고 옷차림 추천을 받는 에이전트** — 도구 두 개가 협업.

사용 예시:
```
사용자: 서울 날씨 보고 오늘 뭐 입을지 추천해줘
↓
[에이전트가 알아서 도구 두 번 호출]
  1. get_weather("서울") → {"temp": 22, "condition": "맑음"}
  2. recommend_outfit(22) → "긴팔 + 청바지"
↓
에이전트: 서울은 22도 맑네요. 긴팔에 청바지 추천드려요.
```

## 어떻게 접근하나 — 바이브 코딩 사고법

> **"코드부터 짜지 말고, 무엇을 만들 건지 / 어떤 구조인지부터 머리에 그려야 합니다.**
> **그게 잡혀야 Copilot 한테도 정확히 시킬 수 있고, 받은 답을 평가할 수도 있어요."**

### 단계별 사고

**1. 내가 뭘 만들 건가?**
사용자가 자연어로 질문 → 시스템이 알아서 외부 정보 가져옴 → 자연어로 답.

**2. 어떤 구조여야 하나?**
LLM 혼자서는 외부 정보 못 가져옴. 그래서 LLM + 외부 도구가 협업하는 구조 필요.
```
사용자 → LLM → (도구 호출 요청) → 우리 코드 → (결과) → LLM → 사용자
```

**3. 한 번에 끝나나?**
아니. 도구 결과를 보고 또 다른 도구가 필요할 수 있음 (날씨 → 옷 추천).
그래서 **반복 (while)** 이 필요.

**4. 언제 멈추나?**
LLM 이 더 이상 도구 안 부르고 **자연어 텍스트로 답할 때** = 끝.

**5. 안전장치는?**
LLM 이 무한히 도구만 부르고 안 멈추면? → `MAX_TURNS` 같은 상한.

→ 이 다섯 단계가 머리에 있으면 코드를 직접 짜든 Copilot 한테 시키든 같은 결과 나옴.

### (2) 망가뜨려보기 — 의도적으로 깨고 무슨 일이 일어나는지 보기

`tool_use.py` 가 동작하면, 이제 일부러 망가뜨려보세요:

| 망가뜨릴 곳 | 무슨 일이 일어나는지 예상해보고, 실제로 해보기 |
|---|---|
| `function_response` 의 dict 를 평범한 텍스트로 | LLM 이 결과를 못 알아들음 |
| `weather_declaration` 의 `description` 을 빈 문자열로 | LLM 이 도구를 안 부르거나 잘못 부름 |
| `get_weather` 함수가 `return None` 하도록 | LLM 이 "정보 없음" 으로 답함 |

→ 이 실험이 **진짜 학습**. 따라치기는 "이렇게 동작한다" 만 보여주지만, 망가뜨려보면 "**왜 이렇게 짜야 하는지**" 가 머리에 박힙니다.

### (3) Copilot 한테 시켜보기 — `agent_loop`

`tool_use.py` 는 **한 턴** 만 처리했어요. 실제 에이전트는 도구 결과 보고 또 부를 수 있어서 `while` 이 필요.

이번엔 **직접 안 짜고 Copilot 한테 시켜봅니다**. 단, 위의 "바이브 코딩 사고법" 5단계가 머리에 잡힌 상태에서.

VS Code 에서 새 파일 `my_agent.py` 만들고 Copilot 한테:

**좋은 프롬프트 예시** (위 5단계 기반):
```
Python 으로 LLM agent loop 를 짜줘.

요구사항:
- google.genai SDK 사용
- 도구 두 개: get_weather(city), recommend_outfit(temp_celsius)
- 사용자 질문 받아서 LLM 이 도구 부르고 결과 받으면 또 도구 부를 수 있게 while 루프
- LLM 이 텍스트로 답하면 (function_call 없으면) 종료
- MAX_TURNS = 5 안전장치
- function_response 형식 표준 따르기
```

**나쁜 프롬프트 (비교용)**:
```
에이전트 짜줘
```
→ 너무 모호. 도구 / SDK / 안전장치 / 형식 다 빠짐. Copilot 이 자기 마음대로 짜고 학생은 그 답이 맞는지 모름.

### (4) Copilot 답 평가하기

받은 코드를 보면서 체크리스트:

- [ ] `while` 루프 있는가? 종료 조건은 무엇인가?
- [ ] `function_call` 이 없을 때 어떻게 처리하나? (텍스트로 답하면 `break` 하는가)
- [ ] `function_response` 형식이 `tool_use.py` 와 같은가?
- [ ] `MAX_TURNS` 같은 안전장치가 있는가?
- [ ] 도구가 두 번 호출되는 시나리오 ("날씨 보고 옷 추천") 가 잘 동작하나?

→ **이 체크리스트를 본인이 만들 수 있어야 진짜 실력.** Copilot 답을 평가하는 능력.

답이 부족하면 추가 프롬프트:
```
방금 코드에 MAX_TURNS 안전장치를 추가해줘.
그리고 종료 조건을 더 명확히 — function_call 이 없으면 break.
```
