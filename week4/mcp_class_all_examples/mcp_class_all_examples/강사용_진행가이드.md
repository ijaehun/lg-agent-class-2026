# 강사용 진행 가이드

## 전체 메시지

오늘 실습의 핵심은 다음 한 문장입니다.

> MCP는 LLM 또는 Agent가 외부 기능을 표준화된 방식으로 호출할 수 있게 해주는 연결 구조입니다.

---

## 1. Warm-up: MCP 없이 Tool 개념 설명

실행:

```bash
python warmup_no_mcp.py
```

설명 포인트:

- 함수 `add()`는 계산 도구이다.
- 함수 `ask_document()`는 문서 검색 도구이다.
- 현재는 같은 파이썬 파일 안에서 직접 호출한다.
- MCP를 사용하면 이런 함수를 외부 Client가 표준 방식으로 호출할 수 있다.

---

## 2. 예제1: 기본 MCP Tool

서버 실행:

```bash
python example1_basic_tools/server_basic_tools.py
```

클라이언트 실행:

```bash
python example1_basic_tools/client_basic_tools.py
```

설명 포인트:

- `@mcp.tool`이 붙은 함수가 MCP Tool로 등록된다.
- Client는 서버에 어떤 Tool이 있는지 확인한다.
- Client는 Tool 이름과 인자를 넘겨 함수를 실행한다.
- 서버는 결과를 반환한다.

---

## 3. 예제2: 문서 Q&A MCP 서버

서버 실행:

```bash
python example2_document_qa/server_document_qa.py
```

클라이언트 실행:

```bash
python example2_document_qa/client_document_qa.py
```

설명 포인트:

- `upload_document`는 문서를 읽고 벡터 DB에 저장한다.
- `ask_question`은 질문을 벡터화하고 관련 문서 chunk를 찾는다.
- Ollama가 있으면 로컬 LLM으로 답변한다.
- Ollama가 없으면 검색된 문장 기반으로 답변한다.
- 이 구조가 RAG의 기본 구조이다.

---

## 4. 예제3: 날씨 API MCP Tool

서버 실행:

```bash
python example3_weather_api/server_weather.py
```

클라이언트 실행:

```bash
python example3_weather_api/client_weather_chatbot.py
```

설명 포인트:

- `get_todays_weather`가 외부 API 호출 Tool이다.
- API Key가 있으면 실제 WeatherAPI를 호출한다.
- API Key가 없으면 샘플 데이터를 사용한다.
- 사용자의 질문이 날씨 관련인지 먼저 판단한다.
- 날씨 질문이면 MCP Tool 호출, 아니면 일반 답변으로 처리한다.
- 한국어 질문은 영어로 변환한 뒤 도시명을 추출한다.

---

## 5. 마무리 설명

세 예제의 의미:

1. 기본 Tool 예제: MCP의 가장 작은 단위 이해
2. 문서 Q&A 예제: 로컬 DB와 로컬 LLM 연결 구조 이해
3. 날씨 API 예제: 외부 API를 Agent Tool로 연결하는 방법 이해

최종 메시지:

> MCP를 사용하면 LLM이 단순 답변 생성기를 넘어, 문서 검색, 데이터 조회, API 호출, 업무 자동화 도구를 사용할 수 있는 Agent로 확장된다.
