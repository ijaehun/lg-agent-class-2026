# LangSmith UI 피드백 가이드

## 1. Run을 Annotation Queue에 넣기

1. LangSmith 프로젝트로 이동
2. Runs 또는 All Runs 클릭
3. `news_summary_chain` 또는 `RunnableSequence` run 선택
4. 우측 상단의 `Add to Annotation Queue` 클릭
5. `prompt_enhance_example_queue` 선택

## 2. Annotation Queue에서 평가하기

1. 왼쪽 메뉴에서 `Annotation Queues` 클릭
2. `prompt_enhance_example_queue` 클릭
3. 평가할 run 선택
4. 오른쪽 패널에서 Feedback 입력

## 3. 평가 항목 예시

| 항목 | 유형 | 의미 |
|---|---|---|
| score | continuous | 요약 품질을 0~5점으로 평가 |
| correctness | categorical | 내용이 맞으면 correct, 틀리면 incorrect |
| notes | freeform | 개선 의견 자유 입력 |

## 4. 피드백 예시

score:
```text
1.5
```

correctness:
```text
incorrect
```

notes:
```text
핵심 문장에 번호를 붙이고, 원문에 없는 내용은 제거해야 합니다.
```

## 5. 수업 질문

- 요약이 원문에 없는 내용을 만들어냈는가?
- 핵심 문장에 번호가 붙었는가?
- 서론, 본론, 결론 흐름이 보이는가?
- 피드백을 반영하면 prompt의 instruction을 어떻게 바꿔야 하는가?
