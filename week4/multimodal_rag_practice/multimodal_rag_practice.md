Python으로 이미지 폴더를 기반으로 질문에 답변하는 이미지 설명 RAG 실습 코드를 작성한다.

파일 이름은 `multimodal_rag_practice.py`로 가정한다.  
이 코드는 재직자 교육에서 사용할 실습용 코드이므로, 코딩 경험이 많지 않은 사람도 전체 흐름을 이해할 수 있도록 함수 단위로 작성하고 주석을 충분히 작성한다.

## 만들고 싶은 결과물

`./images/` 폴더 안에 있는 이미지들을 읽고, 각 이미지의 내용을 먼저 텍스트 설명으로 변환한 뒤, 그 설명들을 검색 가능한 형태로 저장하는 프로그램이다.

이후 사용자가 질문을 입력하면, 프로그램은 질문과 관련성이 높은 이미지 설명을 검색하고, 검색된 이미지 설명을 근거로 답변을 생성해야 한다.

중요한 점은 이미지를 직접 검색하는 것이 아니라, **이미지 → 텍스트 설명 → 임베딩 검색 → 답변 생성**의 흐름으로 동작해야 한다는 점이다.

전체 사용 흐름은 다음과 같다.

1. `./images/` 폴더에서 이미지 파일을 읽는다.
2. 각 이미지의 내용을 시각 정보를 이해할 수 있는 모델로 설명한다.
3. 생성된 이미지 설명을 이미지 파일명, 이미지 경로와 함께 저장한다.
4. 이미지 설명 텍스트를 검색 가능한 벡터 DB로 만든다.
5. 사용자가 질문을 입력한다.
6. 질문과 관련된 이미지 설명을 검색한다.
7. 검색된 이미지 설명들을 하나의 context로 합친다.
8. context와 사용자 질문을 LLM에 전달한다.
9. LLM이 이미지 설명에 근거해서 답변한다.
10. 답변 후 어떤 이미지가 검색되었는지 파일명과 설명을 함께 출력한다.

## 실행 방식

터미널에서 바로 실행할 수 있는 하나의 Python 파일로 작성한다.  
웹 화면은 만들지 않는다.

사용자는 코드를 실행한 뒤 질문을 입력하거나, 코드 안에 예시 질문을 넣어 바로 실행할 수 있도록 한다.

## 입력

입력은 두 가지이다.

첫째, 이미지 파일이다.  
이미지는 `./images/` 폴더 안에 있다고 가정한다.

읽을 이미지 확장자는 다음을 지원한다.

- `.jpg`
- `.jpeg`
- `.png`

둘째, 사용자 질문이다.  
예시 질문은 다음과 같이 둘 수 있다.

```
사람이 직접 냉장고를 사용하고 있는 모습이 포함된 이미지를 요약해주세요.
```

가능하면 `input()`으로 질문을 입력받을 수 있게 만들고, 질문을 입력하지 않았을 때는 위 예시 질문을 사용하도록 한다.

## 출력

실행 결과로 다음 내용을 터미널에 출력한다.

- 읽어온 이미지 파일 수
- 각 이미지에 대해 생성된 설명
- 벡터 DB 생성 완료 메시지
- 사용자 질문
- 검색된 이미지 설명 개수
- LLM 답변
- 검색된 이미지 파일명
- 검색된 이미지 설명

## 이미지 설명 생성 방식

각 이미지를 시각 정보를 이해할 수 있는 로컬 모델에 전달해서 2~4문장 정도의 설명을 생성한다.

이미지 설명을 만들 때는 다음 원칙을 지킨다.

- 이미지에 실제로 보이는 내용만 설명한다.
- 보이지 않는 내용을 추측하지 않는다.
- 핵심 객체, 사람, 행동, 배경을 중심으로 설명한다.
- 설명은 너무 길지 않게 작성한다.
- 업무자가 검색에 사용할 수 있도록 구체적인 명사를 포함한다.

예를 들어 냉장고 이미지라면 다음과 같은 요소를 설명에 포함할 수 있다.

- 냉장고
- 문 열림 여부
- 사람의 사용 행동
- 내부 선반
- 식품 또는 용기
- 주방 환경
- 제품 조작 장면

단, 실제 이미지에 없는 내용은 추가하지 않는다.

## 검색 DB 생성 방식

이미지 자체를 직접 벡터화하지 말고, 이미지 설명 텍스트를 벡터화한다.

각 이미지 설명은 검색 가능한 문서처럼 다루고, 최소한 다음 metadata를 함께 저장한다.

- 이미지 파일명
- 이미지 파일 경로
- 생성된 이미지 설명

검색용 DB는 로컬 폴더에 저장한다.  
저장 경로는 코드 상단에서 수정할 수 있도록 설정값으로 분리한다.

기본 저장 경로는 다음으로 한다.

```
VECTOR_DB_PATH = "./Image_description"
```

## 질문 답변 방식

질문이 들어오면 다음 흐름으로 처리한다.

1. 사용자 질문과 유사한 이미지 설명을 검색한다.
2. 검색된 이미지 설명들을 하나의 context로 묶는다.
3. context와 질문을 LLM에 전달한다.
4. LLM은 이미지 설명에 근거해서 답변한다.
5. 이미지 설명 안에서 답을 찾을 수 없으면 다음 문장을 출력한다.

```
주어진 이미지 설명에서는 해당 질문에 대한 답을 찾을 수 없습니다.
```

답변 생성 시 다음 규칙을 지킨다.

- 검색된 이미지 설명을 근거로만 답변한다.
- 이미지 설명에 없는 내용은 추측하지 않는다.
- 질문과 관련된 내용만 답변한다.
- 답변은 간결하게 작성한다.

## 사용할 로컬 모델 환경

로컬 PC에서 실행 가능한 모델을 사용한다.

모델은 역할별로 분리해서 사용할 수 있도록 작성한다.

1. 이미지 설명 생성용 모델

- 이미지를 입력받아 설명을 생성할 수 있는 VLM 모델을 사용한다.
- 기본 모델명은 `llava:7b`로 둔다.

2. 이미지 설명 검색용 임베딩 모델

- 이미지 설명 텍스트를 임베딩하는 모델을 사용한다.
- 기본 모델명은 `nomic-embed-text`로 둔다.

3. 최종 답변 생성용 LLM

- 검색된 이미지 설명을 근거로 답변하는 모델을 사용한다.
- 기본 모델명은 `llama3.1`로 둔다.

모델명은 코드 상단에서 쉽게 바꿀 수 있도록 설정값으로 분리한다.

```
VLM_MODEL = "llava:7b"
EMBEDDING_MODEL = "nomic-embed-text"
LLM_MODEL = "llama3.1"
```

로컬 모델 서버 주소도 코드 상단에서 수정할 수 있도록 설정값으로 분리한다.

## 코드 구조

초보자가 이해하기 쉽도록 함수 중심으로 작성한다.  
너무 복잡한 class 구조는 사용하지 않는다.

다음 역할을 하는 함수들을 포함한다.

1. 이미지 폴더에서 이미지 파일 목록을 읽는 함수
2. 이미지 파일을 모델에 전달할 수 있는 형태로 준비하는 함수
3. 이미지 설명을 생성하는 함수
4. 이미지 설명을 검색 가능한 문서 형태로 변환하는 함수
5. 이미지 설명 문서들을 벡터 DB로 저장하는 함수
6. 벡터 DB에서 질문과 관련된 이미지 설명을 검색하는 함수
7. 검색된 이미지 설명을 context로 합치는 함수
8. context와 질문을 사용해서 최종 답변을 생성하는 함수
9. 검색된 이미지 파일명과 설명을 출력하는 함수
10. 전체 실행 흐름을 담당하는 `main()` 함수

## 예외 처리와 안내 메시지

다음 상황에서는 사용자가 이해할 수 있는 안내 메시지를 출력한다.

- `./images/` 폴더가 없을 때
- 이미지 폴더 안에 지원되는 이미지 파일이 없을 때
- 이미지 설명 생성용 모델이 실행되지 않을 때
- 임베딩 모델이 실행되지 않을 때
- 최종 답변 생성용 모델이 실행되지 않을 때
- 이미지 파일을 읽을 수 없을 때
- 검색 결과가 없을 때

오류가 발생했을 때는 Python 오류만 보여주지 말고, 사용자가 무엇을 확인해야 하는지 함께 안내한다.

## 설치 안내 주석

파일 맨 위에 실행 전 준비 사항을 주석으로 넣는다.

다음 내용을 포함한다.

- 이 코드는 이미지 설명 기반 RAG 실습 코드라는 설명
- 이미지를 직접 벡터화하는 것이 아니라, 이미지 설명 텍스트를 벡터화한다는 설명
- `./images/` 폴더에 이미지 파일을 넣어야 한다는 설명
- 필요한 Python 패키지 설치 방법
- 로컬 모델 실행 필요
- 이미지 설명용 모델, 임베딩 모델, 생성 모델 설치 필요

설치 안내에는 다음 모델 준비 명령을 포함한다.

```
ollama pull llava:7b
ollama pull nomic-embed-text
ollama pull llama3.1
```

## 중요한 작성 기준

- 교육용 코드이므로 읽기 쉬운 구조를 우선한다.
- 한 파일에서 바로 실행 가능해야 한다.
- 함수 이름은 역할을 이해하기 쉽게 작성한다.
- 각 단계가 실행될 때 현재 어떤 작업을 하는지 print 문으로 보여준다.
- 주석은 “무엇을 하는 코드인지”뿐 아니라 “왜 필요한 단계인지”도 설명한다.
- 구현에 필요한 라이브러리는 적절히 선택해서 사용하되, 초보자가 이해하기 어려운 과도한 구조는 피한다.
- 같은 기능을 하는 import가 중복되지 않도록 정리한다.
- 검색 품질은 이미지 설명 품질에 영향을 받는다는 점을 주석으로 설명한다.

위 요구사항을 만족하는 `multimodal_rag_practice.py` 전체 코드를 작성한다.
