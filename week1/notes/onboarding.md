# 신입사원 온보딩 가이드

## 입사 첫 날
- 인사팀에서 사원증 / 노트북 수령
- 사내 메신저 (Slack) 초대 확인
- 팀 리더 / 멘토와 1:1 미팅

## 첫 주
- 사내 시스템 접속 셋업 (이메일, GitHub, JIRA)
- 팀 소개 + 진행 중 프로젝트 브리핑
- 사내 정책 문서 읽기 (연차 / 재택 / 출장 / 교육)

## 첫 달
- 작은 task 부터 시작 (버그 수정, 문서 개선 등)
- 주간 회의 참석 + 본인 진행 상황 공유
- 멘토와 주 1회 1:1 진행

## 자주 묻는 질문
- **연차는 언제부터?** → 입사 후 6개월 동안 월 1일씩 부여
- **재택근무 가능?** → 주 2회까지, 팀 리더 승인 필요
- **교육비 지원?** → 입사 6개월 이후 가능

자세한 내용은 `policy_*.md` 문서 참고.
